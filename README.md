# Thesis_Project
This repository provides a reproducible, relative-path R bioinformatics pipeline used in a 2026 Master’s thesis to study the genetic architecture and population overlap of experimentally evolved _Drosophila melanogaster_ lines selected for longevity, immune defense, or stress tolerance. It integrates genomic and transcriptomic data and includes custom R scripts to map SNPs to genomic regions, pull gene annotations, and compare candidate-gene features against genome-wide background.
